Quick Describe 0.1.2 is quieter on PCs that can't describe pictures, such as PCs that aren't Copilot+ PCs. There it reads the text in pictures, and now says so once instead of with every result.

## Install

If you have Quick Describe already, it updates itself: Windows checks every few hours and installs the new version while Quick Describe isn't running, and **Help, Check for Updates** checks now.

To install it for the first time, download and open **QuickDescribe.appinstaller**. The other files on this release are what the installer downloads; you don't need to open them yourself.

**You need** a Copilot+ PC with a recent version of Windows 11 for descriptions. On other PCs, Quick Describe reads the text in pictures but doesn't describe them.

## What's changed

- **On PCs that can't describe pictures.** Every result used to start with "No description: Windows' AI isn't available on this PC." Now the result is just the text in the picture, and you hear how many lines there are. The first time, Quick Describe says once why: "This PC can't describe pictures: Windows' image description needs a Copilot+ PC and a recent version of Windows 11. Quick Describe reads the text in them instead." The welcome text, and F1, say so too.
- On a Copilot+ PC with Windows' AI features turned off, each result still says there's no description, since you can turn them back on in Settings, Privacy & security. **Help, Check Windows AI** says which applies to your PC.
- The user guide (Help, User Guide) has a new section, "On a PC that isn't a Copilot+ PC".
