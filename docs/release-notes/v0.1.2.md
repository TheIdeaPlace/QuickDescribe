Quick Describe 0.1.2 is quieter on PCs that aren't Copilot+ PCs, where it reads the text in pictures but can't describe them.

## Install

If you have Quick Describe already, it updates itself: Windows checks every few hours and installs the new version while Quick Describe isn't running, and **Help, Check for Updates** checks now.

To install it for the first time, download and open **QuickDescribe.appinstaller**. The other files on this release are what the installer downloads; you don't need to open them yourself.

**You need** Windows 11 on a Copilot+ PC for descriptions. On other PCs, Quick Describe reads the text in pictures but doesn't describe them.

## What's changed

- **On PCs that can't describe pictures.** Every result used to start with "No description: Windows' AI isn't available on this PC." Now the result is just the text in the picture, and you hear how many lines there are. The first time, Quick Describe says once why: "This PC can't describe pictures: Windows' image description needs a Copilot+ PC. Quick Describe reads the text in them instead." The welcome text, and F1, say so too.
- On a Copilot+ PC with Windows' AI features turned off, each result still says there's no description, since you can turn them back on in Settings, Privacy & security.
