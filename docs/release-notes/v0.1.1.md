Quick Describe 0.1.1 copes better when Windows' AI stops responding, and tells you what's going on instead of leaving you waiting.

## Install

If you have Quick Describe already, it updates itself: Windows checks every few hours and installs the new version while Quick Describe isn't running, and **Help, Check for Updates** checks now.

To install it for the first time, download and open **QuickDescribe.appinstaller**. The other files on this release are what the installer downloads; you don't need to open them yourself.

**You need** Windows 11 on a Copilot+ PC for descriptions. On PCs without Windows AI, Quick Describe reads the text in pictures but doesn't describe them.

## What's fixed

- **When Windows' AI stops responding.** Windows' AI can occasionally stop answering while still reporting itself ready, for example after Windows updates its AI components and before the PC is restarted. Quick Describe used to wait minutes with no result. Now it gives up after a minute and a half and says: "Windows' AI didn't answer. If this keeps happening, restarting the PC may help." The text in the picture still comes, read with Windows' built-in text recognition, without a second wait.
- **The first time on a new PC.** When Windows still needs to download its AI models, Quick Describe gets them ready in the background when it starts. Until they're ready, it reads text with Windows' built-in text recognition, and says the description model is still getting ready instead of waiting on the download.
- **Help, Check Windows AI** now says plainly that Phi Silica, Windows' language model, isn't supported in Quick Describe yet, even when Windows reports it as ready.
- **The log** (Help, Open Log Folder) now records when Windows' AI doesn't respond or can't be used, so a bug report shows what happened.
