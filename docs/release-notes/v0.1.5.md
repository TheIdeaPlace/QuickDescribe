Quick Describe 0.1.5 puts the description in the pictures it saves.

## Install

If you have Quick Describe already, it updates itself: Windows checks every few hours and installs the new version while Quick Describe isn't running, and **Help, Check for Updates** checks now.

To install it for the first time, download and open **QuickDescribe.appinstaller**. The other files on this release are what the installer downloads; you don't need to open them yourself.

**You need** a Copilot+ PC with a recent version of Windows 11 for descriptions. On other PCs, Quick Describe reads the text in pictures but doesn't describe them.

## What's changed

- **The description in pictures saved.** A new choice in **File, Settings**, on unless you turn it off: **Put the description and the text read in each picture Quick Describe saves**. Pictures saved with **Save Described Image**, and the copies **Save every picture** keeps, carry their description inside the file, so File Explorer, photo apps and My Photo Library Described can show it and Windows Search can find it. In File Explorer, turn on the **Comments** column, or open the Details pane, to read the whole description and then the text in the picture. Photo apps read the same as its caption. The picture's Title is the description's first one or two sentences, and its accessibility alt text a version of at most 250 characters. A screen Windows' AI didn't describe gets its text, but no title. Since the text read goes in the file, a screenshot's text goes wherever the file goes, OneDrive included.
- **Cleaner descriptions.** Invisible characters Windows' AI sometimes puts in a description, such as zero-width spaces, are taken out, so a screen reader doesn't stop on them and searching finds the words.
- **Open Pictures Folder.** **File, Open Pictures Folder** opens Pictures\Quick Describe in File Explorer. The first time, it sets the folder to Details view with Name, Date modified, Title, Comments and Size, so each picture's description is right there as you move through the files. File Explorer remembers the view, and a view you change stays yours.
- **Copies of pictures you open.** With **Save every picture** on, pictures you open, drop or copy in File Explorer are now copied to Pictures\Quick Describe too, with their description, so you don't have to describe them again. Your own file isn't changed. A new check box just below Save every picture, on unless you turn it off, controls it. Save Described Image now suggests JPEG for a photo you opened, as it does for the camera.
