Quick Describe 0.1.5 puts the description in the pictures it saves.

## Install

If you have Quick Describe already, it updates itself: Windows checks every few hours and installs the new version while Quick Describe isn't running, and **Help, Check for Updates** checks now.

To install it for the first time, download and open **QuickDescribe.appinstaller**. The other files on this release are what the installer downloads; you don't need to open them yourself.

**You need** a Copilot+ PC with a recent version of Windows 11 for descriptions. On other PCs, Quick Describe reads the text in pictures but doesn't describe them.

## What's changed

- **The description in pictures saved.** A new choice in **File, Settings**, on unless you turn it off: **Put the description and the text read in each picture Quick Describe saves**. Pictures saved with **Save Described Image**, and the copies **Save every picture** keeps, carry their description inside the file, so File Explorer, photo apps and My Photo Library Described can show it and Windows Search can find it. The description is the picture's Title in File Explorer and its accessibility alt text, and its caption holds the description and then the text in the picture. A screen Windows' AI didn't describe gets its text, but no title. Since the text read goes in the file, a screenshot's text goes wherever the file goes, OneDrive included.
