Quick Describe 0.1.3 can save the screenshot it just described, or copy it to the clipboard.

## Install

If you have Quick Describe already, it updates itself: Windows checks every few hours and installs the new version while Quick Describe isn't running, and **Help, Check for Updates** checks now.

To install it for the first time, download and open **QuickDescribe.appinstaller**. The other files on this release are what the installer downloads; you don't need to open them yourself.

**You need** a Copilot+ PC with a recent version of Windows 11 for descriptions. On other PCs, Quick Describe reads the text in pictures but doesn't describe them.

## What's changed

- **Save Screenshot.** After Quick Describe describes the screen, the active window or the focused item, **File, Save Screenshot** (Ctrl+S, or the new Save Screenshot button) saves the picture it took, as a PNG or JPEG file. It suggests a name that says what was taken and when, such as "Active window, Notepad 2026-10-30 14.05.12.png", in your Pictures folder the first time and then wherever you saved last. Your screen reader says "Saved" and the file's name, and the result stays where it was. With no screenshot to save, such as after describing a picture file, Quick Describe says so.
- **Copy Screenshot.** **Edit, Copy Screenshot** (Ctrl+Shift+S, or the new Copy Screenshot button) puts the same picture on the clipboard, to paste into an email, a document or a chat. Your screen reader says "Screenshot copied".
