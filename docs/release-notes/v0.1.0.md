Quick Describe tells you what's on your screen. Press a key from any app and it describes the screen, the active window or the item with focus, and reads out the text in it. It can describe a picture on the clipboard or a picture file too. Everything happens on your PC, with the AI built into Windows on Copilot+ PCs: nothing is uploaded, and there are no accounts.

## Install

Download and open **QuickDescribe.appinstaller**. Windows' App Installer shows Quick Describe and its publisher, Kelly Ford, with an Install button. It installs the Windows App Runtime first if your PC needs it, then Quick Describe for your PC (x64 or Arm64). Windows keeps it up to date from here.

The other files on this release (the `QuickDescribe_*.msixbundle` and the `Microsoft.WindowsAppRuntime.1.8_*.msix` packages) are what the installer downloads. You don't need to open them yourself.

**You need** Windows 11 on a Copilot+ PC for descriptions. On PCs without Windows AI, Quick Describe reads the text in pictures but doesn't describe them.

## What it does

From any app, while Quick Describe is running:

- **Ctrl+Alt+Shift+S** describes the screen.
- **Ctrl+Alt+Shift+W** describes the active window.
- **Ctrl+Alt+Shift+F** describes the item with focus, and what's around it.
- **Ctrl+Alt+Shift+V** describes a picture on the clipboard, or a picture file you've copied.

Quick Describe comes to the front, speaks the description and how many lines of text it found, and puts the full result in a box you can read by line, word or character: the description, then the text in the picture. **Escape** takes you back to where you were (stopping a description that's still going), and the hotkeys keep working. In Quick Describe, **Ctrl+O** opens a picture file, **Ctrl+V** describes the clipboard, and you can drop a picture file on the window. Describe, Description Type chooses Accessible, Detailed, Brief or Diagram descriptions.

## Accessibility

Quick Describe is built for JAWS, NVDA and Narrator. Results are spoken as they arrive, without moving you anywhere you didn't expect. Focus always lands in the Result box, which is an ordinary read-only text box, so your screen reader's reading keys work in it. Every command is on the keyboard, and the menus have the usual Alt keys.

## Good to know

- Windows' AI declines to describe most screens and windows because they're mostly text. Quick Describe then says so and gives you the text instead. Focused items, photos and charts usually get a description.
- Descriptions can be wrong, and can mention things that aren't there. The text Quick Describe reads is usually more reliable than text quoted in a description.
- The first description takes up to half a minute while Windows loads its model. After that, a few seconds.
- Asking questions about a picture isn't possible yet: it needs Windows' on-device language model, which Microsoft lets apps use only with its permission.
