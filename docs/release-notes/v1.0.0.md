This is Quick Describe 1.0. Quick Describe is for getting a quick description: press a key and it describes what you need, using the AI built into Windows, with whatever screen reader you use. This version makes that description easier to use once you have it. You can paste the picture and its description together, and if you choose, keep a record of what you've described, so you never have to describe the same thing twice.

## Install

If you have Quick Describe already, it updates itself: Windows checks every few hours and installs the new version while Quick Describe isn't running, and **Help, Check for Updates** checks now.

To install it for the first time, download and open **QuickDescribe.appinstaller**. The other files on this release are what the installer downloads; you don't need to open them yourself.

**You need** a recent version of Windows 11 on a PC with an AI chip (a neural processing unit, or NPU) for descriptions. Microsoft called these Copilot+ PCs, and many are still sold with that name. Not sure about yours? **Help, Check Windows AI** tells you. On other PCs, Quick Describe reads the text in pictures but doesn't describe them.

## What's new

- **Copy the picture and its description together.** **Edit, Copy Image and Description** (Ctrl+Shift+D) puts both on the clipboard. Paste into Word and you get the picture, with the description as its alt text, and the description below it. Paste into a text box and you get the description. Email and chat apps vary in what they take.
- **Pictures Quick Describe saves include their description.** When Quick Describe saves a picture, with **Save Described Image** or **Save every picture**, it adds the description, and any text it read, to the picture file's details (its metadata): the **Title** and **Comments** File Explorer shows, and the caption and alt text that photo apps read. To see them, select the picture in File Explorer and open the Details pane (Alt+Shift+P), or turn on the Comments column. You can turn this off in **File, Settings**.
- **Your own pictures are never changed.** The description goes only into pictures Quick Describe saves itself. When you open, drop or paste one of your own pictures, Quick Describe reads it and leaves the file exactly as it was.
- **Save every picture can keep the ones you open, too.** **Save every picture** is still off unless you turn it on. With it on, a copy of each picture you open or paste goes into Pictures\Quick Describe too, with its description, so you have a record of everything you've described. A copy doesn't keep the original photo's own details, such as the date it was taken or where. If you only want what Quick Describe captures itself, turn off the new check box under Save every picture.
- **File, Open Quick Describe Pictures Folder** opens Pictures\Quick Describe in File Explorer. The first time, it sets the folder up to show each picture's Title and Comments.
- **One picture at a time.** If you copy or drop several pictures, Quick Describe describes the first.
- **Cleaner descriptions.** Invisible characters Windows' AI sometimes leaves in a description are taken out, so your screen reader doesn't stop on them.
